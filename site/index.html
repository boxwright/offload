Offload is a small daemon for people who own a GPU box and pay for Claude. You give it one line about a change you want. The model on your own GPU does the typing. Claude only plans, reviews, and steps in when the local model stalls. You get a pushed branch, a report, and a message when it needs a decision.

    One harness, two brains
    
    
    How it works
    
    
    Both workers are Claude Code in print mode, inside the same locked-down container. The local one talks to a small proxy in front of your model server, so there is no second agent to install. Brass marks the only places the paid model is used.
    
    
    
      
    
    
    
    
      
    Rate limits are its problem
    On a limit it reads the reset time, waits, and resumes the same session. In our test the resumed review cost a tenth of a fresh one.
    
      
    A budget you set
    It paces Claude use evenly across your week and keeps a share for your own sessions. Ahead of pace, the paid steps wait and the local ones continue.
    
      
    Three questions, ever
    It asks before spending money, publishing, or deleting. Everything else it decides, and writes down in the job's report.
    
      
    Reports, not vibes
    Every job leaves a page: what changed, what it cost, who decided what, and whether the paid model had to rescue a step.

    Who should not install this
    
        
    What it cannot do
    
        
      
          
    • Make a small GPU run a big model. Under 22 GB of VRAM there is nothing to install yet.
      • 
          
    • Use a 32 GB laptop as the host. We measured one: fine at writing, a tenth of the speed at reading, so every session would wait about a minute before its first word.
      • 
          
    • Get vague or sprawling tasks right on its own. It escalates when the local model stalls, and the report says when it did.
      • 
          
    • Run on Windows, or with a Mac as the host. A laptop can drive a Linux box over SSH.
      • 
        
    
      
    
      
    
        
    Models editing code while you sleep
    
        
    Safety, in short
    
        
      
          
    • Every model runs in a container, unprivileged, behind an outbound firewall it cannot change. If the firewall does not start, the worker does not run.
      • 
          
    • The local model's container never holds your Claude login, and cannot reach the internet at all. The paid one can reach Anthropic and nothing else.
      • 
          
    • Your project's tests run with no network at all, because tests are code the model just wrote.
      • 
          
    • An allowlist of tools, not a blocklist. No push, sudo, ssh, docker, curl or pip.
      • 
          
    • The engine makes the one commit and the one push, to a branch, never to your default branch by itself.
      •

    Two commands, and the first installs nothing
    
    
    Install
    
    
    
      
    
        
    1 · Ask your machine
    
        
    Read-only. It reports your GPU and memory, Docker, the NVIDIA container runtime, disk space, and the Claude CLI, and says plainly what is missing.
    
        
    $ curl -fsSL https://raw.githubusercontent.com/boxwright/offload/main/install/preflight.sh | bash
    
      
    
      
    
        
    2 · Install
    
        
    It tells you the size before every download (the model is 17 to 20 GB), offers speculative decoding with a recommendation based on your GPU memory, and never sees your Claude login: you create your own token with claude setup-token.
    
        
    $ curl -fsSL https://raw.githubusercontent.com/boxwright/offload/main/install/install.sh | bash
$ offload doctor     # checks Docker, the sandbox, the model, the token
$ offload demo       # a two-minute job on a sample repo, so you can watch it work
    
      
    
    
    
  
    

  
    
    
    Built in the open, mistakes included
    
    
    The story so far
    
    
    Four things that went wrong while building it, each with a number behind it.
    
    
    
      
    One word in my prompt cost me 415,000 tokens.The daemon looked for the word STUCK. The local agent echoes its instructions, which said "say STUCK".
    
      
    My laptop fell asleep. The job didn't.A 73-minute refactor finished, was reviewed and pushed. I found out two days later.
    
      
    My AI sandbox had a door I forgot to lock.Every model was sandboxed. The tests, which are code the model wrote, ran on the host.
    
      
    It kept calling for backup. I had told it to stare at the code first.One sentence to the planner: 38 cents and a rescue became 13 cents and none.
